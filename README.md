# Health App (React Native)

A React Native health app with a polished onboarding flow and a HealthKit-style dashboard UI.

## What's inside
- Multi-step onboarding and a health dashboard
- Custom typography (Montserrat, Poppins) and Lottie animations for a native feel
- Built with the React Native CLI (Android + iOS)

## Run
```bash
npm install
npm run android   # or: npm run ios
```
